# Index.hr Article Archive (2002-2026)

## Overview
This dataset contains a comprehensive archive of article metadata from the Croatian news portal Index.hr, spanning from its early years in 2002 to February 2026.

## Data Source
Data was aggregated from public XML sitemaps hosted at `https://www.index.hr/sitemap.xml`.

## Dataset Structure
The CSV contains the following columns:
- **url**: The direct link to the article.
- **date**: Publication or last modified date (YYYY-MM-DD).
- **title**: The headline of the article.
- **description**: A short summary or lead paragraph.
